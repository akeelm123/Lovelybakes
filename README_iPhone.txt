Lovelybakes iOS-friendly mobile app package

How to use on iPhone/iPad:
1. Upload this folder to any simple web host, Netlify, Vercel, GitHub Pages, or your own domain.
2. Open index.html in Safari from the hosted link.
3. Tap Share > Add to Home Screen.
4. Open Lovelybakes from the Home Screen icon.

Important:
- iOS does not fully support offline/PWA features when opened as a local file from the Files app. Hosting it on a web link gives the best iPhone experience.
- Recipe and ingredient edits are saved locally in the browser/home-screen app using local storage.
- The app includes Safari-friendly touch icons, offline cache files, mobile display settings, and a clipboard fallback for WhatsApp quotes.
